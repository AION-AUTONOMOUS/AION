# AION AI Vault Value Units

AION may represent the economic value of AI capabilities as **verified valuation units**.

## Target structure

For each supported asset class:
- 10 unique AI value units
- 100,000 USD valuation basis per unit
- 1,000,000 USD aggregate valuation when all 10 units are independently verified

## Critical reality rule

The number 100,000 USD is **not automatically real money** merely because software stores it.

A value unit becomes a real, supportable valuation record only when backed by:
1. a real underlying asset/capability or contractual right,
2. identifiable evidence,
3. an independent or recognized valuation source,
4. verification,
5. an auditable history.

The system therefore fails closed when evidence or valuation verification is missing.

A valuation is not:
- legal ownership,
- cash in the treasury,
- customer revenue,
- a security/token price,
- or permission to transfer money.

The design intentionally prevents fake balance creation.
