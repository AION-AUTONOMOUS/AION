# AION AI Vault Live Value Status

The vault now distinguishes **target valuation** from **verified live value**.

Global target:
- 10 asset classes
- 10 AI value units per class
- 100,000 USD per verified unit
- 10,000,000 USD target valuation

The live verified value starts at zero until real asset IDs, evidence and valuation sources are supplied and verified.

Status:
- NO_VERIFIED_VALUE
- PARTIALLY_VERIFIED
- VERIFIED_TARGET_REACHED

This prevents the dashboard or AI from presenting a target as existing cash or existing asset value.
