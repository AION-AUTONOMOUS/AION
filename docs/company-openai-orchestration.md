# AION Company OpenAI Orchestration\n\nThe company orchestrator converts a goal into department work and dispatches tasks through the durable Worker Runtime path.\n\n`Goal -> dispatchTask -> Redis durable queue -> Worker Runtime -> OpenAI -> evidence -> verification -> outcome`\n\nThe fleet contains 20 departments and 10,000 registered roles. The roles are registry entries; execution uses bounded runtime concurrency rather than 10,000 simultaneous model processes.\n\nSensitive financial, governmental, legal-action, and other guarded operations remain subject to AION policy and owner approval.\n
