# AION OpenAI Company Orchestration

All 20 AION departments are routed through one company-wide orchestration layer.

Each department receives an appropriate OpenAI mode:
- frontier: strategy/product/finance/legal/compliance
- engineering: engineering/security/QA/DevOps
- research: research/data
- volume: customer-facing and high-volume functions

The 10,000-agent registry remains truthful: it is a registry of executable roles, scheduled onto real worker capacity. A completed task requires a real OpenAI response or a registered adapter result.

Sensitive external actions remain owner-approved. Political targeting remains blocked.
