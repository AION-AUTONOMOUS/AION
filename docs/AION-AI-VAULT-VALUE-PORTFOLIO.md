# AION AI Vault Value Portfolio

## Structure

AION now defines a portfolio target of:

- 10 asset classes
- 10 unique AI value units per class
- 100,000 USD target valuation per verified unit
- 1,000,000 USD target valuation per class
- 10,000,000 USD target valuation across all 10 classes

## Reality gate

The 10,000,000 USD figure is a **target valuation structure**, not cash and not an existing treasury balance.

Only verified units contribute to `verifiedValueUsd`.

Each accepted unit requires:
- a real evidence reference,
- an identifiable valuation source,
- verification,
- auditable provenance.

Unverified units remain `requires-real-evidence` and contribute zero to verified value.

This prevents the AI from creating money or inventing assets by writing numbers into software.

## Example

Bonds:
10 verified AI value units × 100,000 USD = 1,000,000 USD verified valuation.

Across ten asset classes:
100 verified units × 100,000 USD = 10,000,000 USD verified valuation.

That result is only valid after the underlying evidence and valuation for every unit have actually been verified.
