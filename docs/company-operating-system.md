# AION Company Operating System

AION now has a single company-wide orchestration layer above the 20 departments and the deterministic 10,000-role fleet.

## Operating contract

Real work follows:

OpenAI Intelligence -> Department routing -> registered agent role -> bounded worker runtime -> verification -> durable evidence -> learning.

The 10,000 entries are executable software-agent roles. They are scheduled onto a bounded pool of real workers rather than pretending that 10,000 independent model processes are continuously running. This preserves truthful execution state and avoids uncontrolled API spend.

Ordinary work can run autonomously. Money movement, mainnet actions, legal decisions, and other sensitive external actions remain owner-approved or fail closed. Political targeting is blocked.

## Legal formation

AION can prepare jurisdiction research, formation documents, compliance checklists and filing data. It cannot truthfully register a legal entity without the owner's required identity/KYC information and statutory fees. No government registration should be claimed until the government registry returns an official confirmation.
