## 8.3 Redis

يستخدم Redis في بعض مسارات الحالة التشغيلية والمهام عند تهيئته وربطه بنجاح.

تقارير SI Exchange السابقة وثقت Redis Volume باسم `redis-volume` بسعة 500MB ومجلد تركيب `/data`، مع حالة خدمة تاريخية Offline في وقت الفحص.

**تعليمات حماية:**

- لا تحذف Volume.
- لا تفصل Volume.
- لا تعِد تهيئة Redis.
- لا تبدأ خدمة متوقفة دون خطة حفظ واستعادة معتمدة.
- لا تعتبر وجود Volume إثباتًا لوجود نسخة احتياطية قابلة للاستعادة.

## 8.4 قواعد البيانات

وجود كود يدعم PostgreSQL لا يثبت وجود قاعدة بيانات إنتاج متصلة.

تقارير سابقة لم تثبت وجود خدمة PostgreSQL ضمن Railway الخاص بـ SI Exchange، كما لم تحسم وجود مزود خارجي.

الحالة: UNKNOWN.

## 8.5 CI/CD

يجب تشغيل الاختبارات والتحقق من تغييرات المصدر قبل الدمج والنشر.

نجاح الاختبارات يثبت نجاح نطاق الاختبارات المنفذ فقط، وليس جميع وظائف المنتج.
