# AION Jazan Evidence Desk — Static Demo

Arabic RTL, zero-dependency prototype for the Jazan incorporation workstream.

## Run locally
Open `index.html` directly in a current browser. No package install, server, API key, database, account, or paid service is required.

## Included
- Current workstream summary with explicit legal/financial status boundaries.
- Filterable task ledger.
- Downloadable Markdown status report.
- Direct links to Saudi Ministry of Commerce and Monsha'at sources.
- Mobile responsive layout and keyboard-visible focus.

## Security and limitations
- All task information is illustrative and hard-coded.
- No network calls, analytics, external scripts, cookies, local/session storage, credentials, or persistence.
- This prototype does not file government forms, contact agencies, confirm eligibility, register a company, or establish funding.
- Changes made in the UI are not saved.
